# Barbearia do Alemão — front-end

Abra `index.html` em um navegador moderno para visualizar o site. Mantenha a pasta `assets` junto dos arquivos HTML, CSS e JavaScript. As fotos usadas pelo site estão em `assets/optimized` e as imagens PNG originais foram preservadas na pasta `assets`.

Os botões de agendamento e consulta dos planos direcionam para a plataforma externa AppBarber: https://sites.appbarber.com.br/barbeariadoalem-gkiu. O site não coleta dados pessoais nem cria reservas.

Os preços e as durações dos serviços estão centralizados no início de `script.js`; a listagem e os seis destaques usam a mesma fonte. Os três planos permanecem descritos no HTML, sem uma segunda cópia desses valores em lógica de agendamento.

O mapa usa o endereço informado e oferece um link externo para traçar a rota. O perfil oficial do Instagram e o horário de domingo não foram informados.

# Barbearia do Alemão — front-end

Abra index.html em um navegador moderno para visualizar o site. Mantenha a pasta assets junto dos arquivos HTML, CSS e JavaScript.

O fluxo de agendamento é uma prévia visual: os horários são exemplos, os dados digitados não são enviados ou salvos e nenhuma reserva é criada. Conecte uma agenda e um backend antes de aceitar agendamentos reais.

O mapa usa a busca do endereço fornecido, sem coordenadas inventadas, e oferece um link externo para traçar a rota. O perfil oficial do Instagram e o horário de domingo não foram informados.
